# Python Bot Template

Copy this directory to bootstrap a new Python bot package under `bots/python/`.

## TODO Checklist

1. Rename folder `template` → your bot name (example: `eth_breakout_1h`)
2. Update `__main__.py` description, strategy import, and strategy registry key
3. Replace `TemplateStrategy` logic in `strategy.py`
4. Replace `config.yaml` strategy section with your parameters
5. Update this README with strategy thesis, runbook, and risk notes

## Run

```bash
python -m bots.python.template
```
